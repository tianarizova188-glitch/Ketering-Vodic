Кетеринг – водич: упатство за објавување (бесплатно)

1. Отвори app.netlify.com/drop (најлесно од компјутер).
2. Повлечи ја ЦЕЛАТА папка (или овој ZIP) на кутијата. index.html мора да е во главниот директориум.
3. Добиваш адреса од типот нешто.netlify.app. Направи бесплатен профил за да ја задржиш.
4. iPhone: отвори ја адресата во Safari, допри го копчето за споделување, па „Add to Home Screen".
   Android: во Chrome допри ги трите точки, па „Install app" или „Add to Home screen".
5. Работи и без интернет откако ќе се отвори еднаш. Податоците (нарачката што ја пополнуваш) се чуваат само на уредот.
6. За нова верзија: качи ги новите датотеки на истата страница (Deploys), па отвори ја апликацијата двапати.
